# Streaming WebM regression fixture

`chromium-streaming-opus.webm` was generated by Chromium 149.0.7827.196
using an AudioContext oscillator and MediaRecorder with
`audio/webm;codecs=opus` and `start(250)`. Recording stopped after a
one-second timer. It contains 960 ms of encoded Opus audio (15,665 bytes).
No microphone, user recording, or provider service was used.

This is the browser's unmodified output, not a remuxed or repaired file.
It has an unknown-length segment and no Duration element, reproducing the
normal Chromium dictation failure with the metadata-only duration parser.

To regenerate from `src/packages` (requires the frontend's Playwright
dependency and local Chromium):

```sh
node server/ai/fixtures/record-chromium-webm.cjs
```

Set `CHROMIUM_PATH` for a different Chromium executable. Timing and encoded
bytes can vary between runs; update the exact-duration assertion if needed.
Normal tests use the checked-in fixture and require neither Chromium nor
FFmpeg. The over-limit tests remux its encoded packet to create long WebM
recordings without waiting 90 seconds.
