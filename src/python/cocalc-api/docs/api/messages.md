# Legacy message wrapper

The client still has `hub.messages.send()` and `hub.messages.get()`, but the
current HTTP hub bridge does not allow either RPC. The old public message
center is not a supported messaging integration for new work.

For communication in a research project, see
[project chat](https://cocalc.ai/docs/collaboration/chat). Review the
[Python compatibility guide](../index.md) before using another client method.
