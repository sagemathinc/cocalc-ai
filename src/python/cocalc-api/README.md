# CoCalc Python API client

`cocalc-api` is a Python client for CoCalc's HTTP Conat bridges. The current
server accepts only a subset of the methods still present in this client.
Read the [compatibility and capability guide](docs/index.md) before choosing
an API. Method existence does not establish that an API key may call it.

Package: <https://pypi.org/project/cocalc-api/>
